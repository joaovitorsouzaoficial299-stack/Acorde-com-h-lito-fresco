# Acorde com Hálito Fresco

Landing page responsiva em React + Vite, com quiz interativo, tela de resultado e página de oferta.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Status da primeira versão

- Landing page com CTAs para iniciar o quiz.
- Quiz de 6 etapas com progresso e navegação voltar/continuar.
- Resultado educativo com recomendação de conteúdo, sem diagnóstico.
- Página de oferta com apresentação dos quatro materiais e FAQ.
- Modal informativo no botão de compra.
- Checkout real e entrega automática ainda precisam ser conectados a um provedor.

## Deploy

Importe este repositório na Vercel. O framework Vite deve ser detectado automaticamente; o comando de build é `npm run build` e a pasta de saída é `dist`.

## Nota de saúde

Material educativo, sem promessas de cura ou eliminação garantida do mau hálito. Mau hálito persistente deve ser avaliado por um cirurgião-dentista.
